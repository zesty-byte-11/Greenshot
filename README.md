## 📖 About

Greenshot is an open source screen capture tool originally built for Windows productivity workflows. It sits quietly in the notification area and springs into action with a hotkey: grab the entire desktop, one window, the last active window, or drag a rectangle around exactly what you need. The built in image editor covers the everyday jobs most people want after a capture, adding arrows, boxes, numbered steps, text, highlights, obfuscation and a drop shadow, and the export options push finished images to the clipboard, a file, a printer or an external editor. Recent builds focus on faster startup, better multi monitor handling and cleaner high DPI rendering on modern displays.

If you came looking for a Greenshot download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes. Everything below describes the standard desktop installer, which is the same build used by most people running Greenshot day to day. The repository you are reading is a documentation page only: it explains how to obtain and run the app, not a redistribution point for binaries.

**Good for:** office workers capturing meeting notes · support agents documenting issues · teachers building step by step guides · developers filing bug reports · students assembling assignments · bloggers preparing tutorials · anyone replacing the Windows Snipping Tool.

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer closes without finishing | Reboot, close other setup windows, then run the installer again. |
| Hotkeys do not respond | Open preferences, confirm shortcuts are enabled and not clashing with another app. |
| Screenshots look blurry on a 4K screen | Set display scaling to 100 percent or enable DPI awareness in preferences. |
| Captures save to an unexpected folder | Check the output path and filename pattern in the save settings. |
| Tray icon missing after launch | Look in the hidden icons area and enable the always show option. |
| Multi monitor capture grabs the wrong screen | Select the target display in the capture mode dropdown before shooting. |
